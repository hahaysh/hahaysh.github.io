## Project Overview

Performed load testing and performance tuning for Yonsei Severance Hospital's "Yonsei 3.0" hospital information system, focused on identifying and resolving performance bottlenecks under realistic load conditions.

## Key Contributions

- Designed and executed load tests simulating hospital system usage patterns
- Tuned system performance based on load test findings
- Introduced real-time monitoring using Azure Monitor and Application Insights

## Technical Stack

- **Load Testing**: Azure Load Testing, JMeter
- **Monitoring**: Azure Monitor, Application Insights

## Impact

Performance tuning roughly doubled the system's load handling capacity, and the introduction of real-time monitoring cut incident frequency by roughly 50%.
