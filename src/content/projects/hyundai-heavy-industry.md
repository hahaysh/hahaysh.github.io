## Project Overview

Led the design, testing, and deployment of a cloud-based system migration for Hyundai Heavy Industry, moving existing systems into a DevOps development and deployment environment.

## Key Contributions

- Designed the cloud-based system migration approach
- Built and tested the new DevOps environment
- Automated deployment steps that were previously manual

## Technical Stack

- **CI/CD Platform**: Azure DevOps
- **Containerization**: Docker
- **Development**: Visual Studio, C#

## Impact

Automation of the deployment process reduced deployment time by roughly 50% compared to the prior manual process.
