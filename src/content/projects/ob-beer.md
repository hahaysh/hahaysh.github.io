## Project Overview

Transformed OB Beer's marketing operations by migrating legacy systems to a modern cloud-native platform. The solution enabled real-time campaign management and data-driven decision making.

## Key Contributions

- Migrated monolithic applications to microservices on Azure App Service
- Implemented real-time data analytics using Azure Cosmos DB
- Designed reporting dashboards with Power BI for business intelligence
- Established automated marketing workflows using Logic Apps
- Implemented security and compliance controls for customer data

## Technical Stack

- **Compute**: Azure App Service
- **Database**: Azure SQL Database, Azure Cosmos DB
- **Analytics**: Power BI
- **Integration**: Logic Apps, Service Bus
- **Storage**: Azure Blob Storage

## Results

The platform enabled marketing teams to launch campaigns 5x faster with better targeting and ROI measurement capabilities.
