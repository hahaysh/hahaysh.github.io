## Project Overview

Designed and operated a DevOps pipeline for OB Beer, improving collaboration between development and operations teams and introducing automated code quality checks into the delivery process.

## Key Contributions

- Configured Azure DevOps-based CI/CD pipeline for the development team
- Introduced continuous monitoring with automated rollback capability
- Integrated SonarCloud and Black Duck for code quality and software composition analysis
- Delivered DevOps system configuration, operation, and training to the client team

## Technical Stack

- **CI/CD Platform**: Azure DevOps
- **Code Quality**: SonarCloud, Black Duck
- **Development**: Visual Studio, C#

## Results

The new pipeline improved dev-ops collaboration and cut the deployment cycle by roughly half, while automated rollback improved service stability.
