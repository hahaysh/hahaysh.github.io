## Project Overview

As a Microsoft Certified Trainer, I led a company-wide digital transformation initiative for KT, one of South Korea's largest telecommunications companies. KT was pursuing a strategic shift from legacy on-premises infrastructure to Microsoft Azure, coupled with an adoption of GitHub Copilot and Azure AI technologies. My role was to build technical competency across the engineering organization through structured training, hands-on labs, and real-world PoC guidance.

## Challenge

- **Legacy Migration**: Multiple critical on-premises services needed Azure migration without downtime
- **Technical Readiness Gap**: Engineers lacked hands-on experience with Azure, AI, and modern DevOps practices
- **Strategic Alignment**: Company-wide adoption required deep understanding, not just high-level overviews
- **Multi-layer Load Balancing**: Complex requirements for both HTTP-based and non-HTTP traffic distribution across hybrid environments

## Solution & Key Contributions

### 1. Structured Training Program
- Delivered 40+ instructor-led training sessions combining Azure Fundamentals (AZ-900), Administration (AZ-104), and DevOps (AZ-400)
- Created hands-on labs where engineers directly provisioned and managed Azure resources
- Designed scenario-based exercises reflecting KT's actual business use cases

### 2. Migration Architecture Guidance
- **On-Premises to Azure Patterns**: Provided guidance on Lift & Shift, Rehost, Refactor strategies
- **Load Balancing Strategy**: Differentiated between traffic types and provided architectural recommendations:
  - **Non-HTTP Layer 4**: Azure Load Balancer for internal services, Traffic Manager for global distribution
  - **HTTP Layer 7**: Application Gateway for single-region load balancing, Azure Front Door for multi-region failover and DDoS protection
- **Infrastructure-as-Code**: Shared Bicep/ARM templates for repeatable deployment patterns

### 3. Hands-On PoC Delivery
- Provided sandbox environments where teams executed end-to-end migration scenarios
- Walked engineers through real networking challenges (security groups, DNS, hybrid connectivity)
- Created migration runbooks tailored to KT's existing service topology

### 4. Copilot & AI Adoption
- Introduced GitHub Copilot for enhanced development productivity
- Showcased Azure OpenAI and Azure AI Services for intelligent automation opportunities
- Enabled teams to experiment with AI-assisted code generation and documentation

## Business Impact

- **Feedback Score**: 95+ average rating from all delivered training sessions
- **Global Recognition**: Selected as top 100 trainer globally (across Asia, EMEA, Americas)
- **Organizational Capability**: 100+ engineers gained hands-on competency to drive subsequent Azure migrations independently
- **Risk Reduction**: Teams gained confidence and clear architectural patterns before touching production workloads

## Key Takeaways

This engagement demonstrated that enterprise transformation requires more than knowledge transfer—it requires structured hands-on practice in realistic environments. By combining formal curriculum with live problem-solving and custom migration guidance, KT's engineering teams were equipped not just to understand Azure, but to architect and deploy business-critical applications on it.
