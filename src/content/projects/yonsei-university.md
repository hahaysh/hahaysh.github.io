## Project Overview

Developed a comprehensive online learning platform for Yonsei University to deliver AI and cloud computing courses with interactive hands-on labs and real-world project assignments.

## Key Contributions

- Designed microservices architecture for scalability and reliability
- Built interactive lab environments with automated Azure resource provisioning
- Implemented progress tracking and analytics for learning outcomes
- Created content management system for course developers
- Established CI/CD pipeline for continuous platform updates

## Technical Stack

- **Frontend**: Next.js, React
- **Backend**: Node.js, Azure App Service
- **Database**: Azure Cosmos DB
- **Infrastructure**: Azure Container Instances
- **Development**: Azure DevOps, GitHub

## Impact

The platform successfully delivered quality AI and cloud education to thousands of students, becoming a model for technical education programs.
