## Project Overview

Implemented a comprehensive AI-driven supply chain solution for Hyundai Motor combining IoT data collection, analytics, and predictive maintenance to optimize manufacturing operations.

## Key Contributions

- Architected IoT data ingestion pipeline using Azure IoT Hub and Event Hubs
- Built predictive maintenance models using historical equipment data
- Designed real-time analytics dashboards for supply chain visibility
- Implemented anomaly detection for early warning systems
- Created mobile apps using Power Apps for on-site operations

## Technical Stack

- **IoT**: Azure IoT Hub, IoT Edge
- **Analytics**: Azure Synapse Analytics
- **AI/ML**: Azure Cognitive Services, Custom Vision
- **Integration**: Azure Logic Apps, Service Bus
- **Mobile**: Power Apps, Power Automate

## Results

The solution enabled proactive maintenance reducing unplanned downtime and optimizing supply chain operations across manufacturing facilities.
